★ 觉得这份合集有用，就去 GitHub 点个 Star：收藏起来方便回来看新收录的项目，也能让更多人找到它。

收录标准：画面由代码绘制或渲染，不用视频或图像生成模型，也不靠 Blender 等 3D 软件出画面。主流画风要求星数 1000 以上，或近一年仍在更新且星数 200 以上；小众画风区放宽到近一年内有更新、星数 20 以上；让 Claude / Opus 等 AI 编程助手写代码出片的项目放宽到 50 以上，照样按画风归类。已归档的仓库不收。

星数、最近提交时间和许可证来自 GitHub，更新于 2026-11-15。状态按最近一次推送计算：半年内为「活跃」，两年内为「放缓」，超过两年为「停更」。

许可证写「见仓库」的，是 GitHub 没能自动识别的情况。打算商用前，请到仓库里核对许可证原文。
