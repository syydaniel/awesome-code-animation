收录标准：画面由代码绘制或渲染；GitHub 星数 1000 以上，或近一年仍在更新且星数 200 以上；已归档的仓库不收。

星数、最近提交时间和许可证来自 GitHub，更新于 __DATE__。状态按最近一次推送计算：半年内为「活跃」，两年内为「放缓」，超过两年为「停更」。

许可证写「见仓库」的，是 GitHub 没能自动识别的情况。打算商用前，请到仓库里核对许可证原文。
